# Fitness Club Management System

A sleek, responsive web application for fitness centers and gyms. This project features a professional front-end for members and a robust administrative panel for content management.

## ✨ Features

- **Dynamic Homepage:** Customizable banners and "Why Choose Us" sections.
- **Membership Plans:** Manage different fitness plans, pricing, and features.
- **Expert Trainers:** Showcase your team of experts with profiles.
- **Portfolio & Video Gallery:** Display gym facilities and workout videos.
- **Client Testimonials:** Manage and display user reviews and ratings.
- **Contact & Social Integration:** Built-in contact forms and social media links.
- **Admin Dashboard:** Secure admin panel to update all website content in real-time.

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP (Vanilla)
- **Database:** MySQL / MariaDB

## 🚀 Getting Started

1. **Database Setup:**
   - Create a database named `pptoolkj_fitness`.
   - Import the provided `db.sql` file.
   - Configure your credentials in `db.php`.

2. **Installation:**
   - Clone or upload the files to your web server.
   - Ensure the `admin/` directory is secured.

3. **Admin Login:**
   - Access the dashboard at `/admin`.
   - Default credentials: `admin@mail.com` / `admin123`.

## 📂 Project Structure

- `index.php`: Main landing page.
- `plans.php`: Membership options.
- `portfolio.php`: Gallery and videos.
- `/admin`: Administrative interface.
- `/api`: Backend handlers for form submissions.
